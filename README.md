# Street × Riad

A Moroccan street fashion e-commerce website that fuses traditional Moroccan craftsmanship with contemporary urban culture.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** for bundling
- **Tailwind CSS v4** for styling
- **Wouter** for client-side routing
- **shadcn/ui** components

## Getting Started

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm start
```

## Deploying to Vercel

1. Push this repository to GitHub.
2. Import the project in [Vercel](https://vercel.com).
3. Set the **Build Command** to `pnpm build` and **Output Directory** to `dist`.
4. Deploy.

SPA routing is handled via `vercel.json`.
